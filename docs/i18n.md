# Languages

See ADR 0006 for the reasoning.

- Locales: `en` (default, unprefixed) and `id` (`/id/...`). Config in `src/i18n/config.ts`.
- **Interface text:** `src/i18n/ui.ts`, use `t(locale, 'key')`. Every key needs both languages (TypeScript enforces it).
- **Content:** Posts, Projects and About have separate English and Indonesian collections in the Studio. A Translation pairs with its original by **identical slug**.
- **Archive, Tags, Albums, Series** are not translated; their pages exist under both locales with translated chrome.
- **Fallbacks:** `/id/writing/x` with no Indonesian Translation renders the English text with a notice, `noindex`, canonical → `/writing/x`, no hreflang, excluded from the sitemap (`src/i18n/untranslated-routes.ts`).
- **Toggle:** `LanguageToggle.astro` swaps the locale prefix of the current path. Every route exists in both locales, so it never 404s.
- **Links:** build them with `localizePath(routes.x(slug), locale)`.
- **RSS:** `/rss.xml` (English Posts) and `/id/rss.xml` (Indonesian Translations only).
